# 架构

```
                 宿主进程（任意 Android + OpenGL ES 应用）
                              │
                    eglSwapBuffers / WithDamageKHR / 2KHR
                              │  ← Dobby inline hook
              ┌───────────────▼────────────────┐
              │ ui/ui_overlay.cpp              │  渲染接管层
              │  · 取 surface 尺寸（四路兜底）  │
              │  · NewFrame / Render           │
              │  · 段级崩溃保护 + 分级降级      │
              └───────────────┬────────────────┘
                              │ ui_layer::Frame(W, H, dt)
              ┌───────────────▼────────────────┐
              │ ui/ui_menu.cpp                 │  界面本体
              │  · HandleInteraction  （手势）  │
              │  · DrawMenu           （菜单）  │
              │  · DrawBall           （悬浮球）│
              │  · 主题 / 控件 / 分页 / 模糊    │
              └───────────────┬────────────────┘
                              │ ui::prefs
                        ui_prefs.h  ←→  /sdcard/imgui_ui.txt
```

## 两层怎么划分

`ui_overlay.cpp` 只关心「什么时候能画」：

1. `Init()`（`__attribute__((constructor))`）里挂三个 swap 入口 + `ANativeWindow` 尺寸 + `MotionEvent::copyFrom`
2. 每次 swap 之前取尺寸；尺寸到手且还没初始化，就建 ImGui 上下文（字体、后端、偏好）
3. 每帧算 `dt`（限幅 1 ms ~ 100 ms）→ `ui_layer::Frame()`
4. `EndFrame()` + `Render()` + `ImGui_ImplOpenGL3_RenderDrawData()`

`ui_menu.cpp` 只关心「画成什么样」：

- `HandleInteraction`：悬浮球命中/拖拽/开合、图片长按拖动、右下角缩放、侧滑条滚动
- `DrawMenu`：面板底 → 主题色边环 → 侧栏 → 图片 → 诗句 → 分区按钮 → 内容区（双页插值）→ 缩放手柄 → 顶点变换
- `DrawBall`：三层同心圆（外白边 + 黑底 + 贴图）+ 高光
- 控件全部自绘进主窗口 DrawList（不用 `BeginChild`，否则子 DrawList 不跟随顶点变换）

两者之间只有 `ui/ui_layer.h` 五个函数：

```cpp
void     Frame(float W, float H, float dt);
bool     MenuOpen();
void     ToggleMenu(bool open);
void     SetBallTexture(uint32_t tex);
uint32_t BallTexture();
```

## 崩溃隔离

三个层次：

1. **段级**：`FLCY_SEGMENT("名字", { ... })` 用 `sigsetjmp` + `SIGSEGV` handler 包住一段绘制，
   崩了只跳过这一段并写日志。覆盖了 GL 探针、旋转查询、`NewFrame`、模糊。
2. **分级降级**：L0 全功能 → L1 无模糊（模糊在某些 Adreno 驱动上必崩）→ L2 仅菜单。
   每一级触发都会写 `FlcyHook`/`ImGuiHook` 日志，状态不持久化。
3. **hook 重试**：`Init()` 阶段 libEGL 可能还没加载，首挂失败就起后台线程每 200 ms 重试，
   最多 60 秒。重试只碰 hook 安装，不动 GL 状态。

## 动画系统

| 动画 | 实现 |
|---|---|
| 菜单开合 | `g_animT` 0→1 线性推进，套 `cubic-bezier(0.36,0.40)`（开）/ `(0.32,0.30)`（关）；缩放 0.10→1.0 与中心点位移联动，alpha 提前 1.8× 到位 |
| 分区切换 | `g_pageX` 0→1，旧页滑出 + 新页滑入同时进行，两页 alpha 交叉 |
| 开关 | 每个 slot 独立的 220 ms 线性进度 + `cubic-bezier(0.34,1.56,0.64,1)` 过冲，滑块位置由缓动值驱动 |
| 按压 | 半隐式欧拉弹簧（k=320 / damping=22），按下更硬、松手更软，钳制 0.90~1.12 |
| 按钮 | 同上弹簧，并把底色按进度往白色提亮 20% |

## 面板模糊

1. `blur::runRegion(x, y, w, h, screenH)`：把菜单矩形 `glCopyTexSubImage2D` 到 FBO，着色器做两趟高斯
2. 拿到纹理后画在**背景 DrawList**（`GetBackgroundDrawList`），脱离菜单窗口的顶点变换
3. 用 `AddImageRounded` 而不是 `AddImage` —— 后者圆角会变方角
4. UV 上下翻转（`(0,1)→(1,0)`），因为 `glCopyTexSubImage2D` 第 0 行是矩形底边

## 触摸坐标

`MotionEvent::copyFrom` 被 hook 后，事件既交给宿主也复制给 `ImGui_ImplAndroid_HandleTouchEvent`。
旋转拉伸由 `touch_transform.h` 的矩阵 + `touch_calib.h` 的四角拟合校准处理，
surface / window / display 三套尺寸都写进 `touch::calib`，横竖屏切换不需要重进。
